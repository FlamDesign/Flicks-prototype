# The brief

Goal: enough to plan a great Flick in the fewest possible questions (ideally 2, never more than 4).

## Infer first
From the prompt, any images and any website, work out:
- the product or offer, and its options (colours, models, flavours, sizes, scenes);
- the brand (name, colours, tone);
- where it runs (an ad size implies ads; "my site" implies embed; "share" implies a link);
- the audience, if obvious.
Don't ask for anything you can infer. If a web address is given, read it before asking anything.

## Ask only what changes the plan
In order of value:
1. **What switches?** Colours, products, people, scenes or offers. (Skip if obvious.)
2. **Where does it run?** Ads, website, link. (Sets size, length and CTA.)
3. **Look**: a visual choice (layouts, palettes), never a text question about style.
4. **Prices and links**, only if not on the website and the user wants them shown.

## How to ask
- One question per card, tappable answers of 1 to 4 words, a "Decide for me" option.
- Visual questions use layouts or palettes, not words.
- Ask for product photos or a logo once, with request_assets, and only when there's no website.
- If the user is vague or says "you decide", decide and move on; say what you chose in one line.

## Stop asking when
You can name the product, what switches (2 to 5 options), the format, and the look. Then plan.
