# Shots and motion

You're the director. Choose the energy, camera, moves, cuts and pacing that make this idea land for
this brand and audience: calm or bold, one continuous shot or several. Show the user the plan as the
storyboard (one line per beat) before any video is made.

## Keep in mind
- Something should be happening from the first frame; a static video rarely makes people tap.
- The swap is clearly visible for at least 40 to 50% of the video, in the first frame, and in a
  clear hero moment near the end.
- Leave room for the design (the clear zones below).

## Hard limits
- No shaky handheld motion and no accidental jump cuts.
- Variations are edits of this video, so they follow its camera, motion and timing. Keep what
  changes between variations to one thing, with the same shape and size, so they still match.

## Camera words (widely understood; use them in plans and prompts)
| Group | Term | Means |
|---|---|---|
| Size | wide | the whole place, the subject small |
| | full | a person head to toe |
| | medium | waist up |
| | medium close-up | chest up |
| | close-up | a face, or a product filling most of the frame |
| | extreme close-up (macro) | a detail: texture, a droplet, a stitch |
| Angle | eye level | neutral, relatable |
| | low angle | camera below, looking up: powerful |
| | high angle | camera above, looking down |
| | top-down | straight down: flat lays, food |
| | three-quarter | between front and side: the classic hero angle |
| | side profile | from the side: silhouette, movement |
| Move | static | the camera doesn't move: premium, safest |
| | slow push-in | the camera moves slowly toward the subject: builds attention |
| | pull-out | moves away: reveals the place |
| | pan / tilt | turns left-right / up-down from one spot |
| | truck | slides sideways, same angle: adds depth |
| | pedestal | rises or lowers, same angle |
| | orbit | circles the subject: product showcase |
| | tracking | moves alongside a moving subject |
| | crane | rises high to reveal a large place |
| Focus | shallow depth of field | subject sharp, background soft |
| | deep focus | everything sharp |
| | rack focus | focus shifts from one thing to another |

## Clear zones for the design
Keep the swap and faces out of the areas the text, button and thumbnail strip will use:

| Size | Keep clear |
|---|---|
| 1080×1920 (9:16) | the bottom third (button and strip) and the top 8% |
| 1080×1080 (1:1) | the bottom quarter |
| 1920×1080 (16:9) | the left third (text) and a strip along the bottom or right |
| 300×600, 320×480 | the bottom quarter |
| small display sizes | the bottom third; keep the subject in the top two thirds |

## Before building
Check the plan: something is happening, the swap reads clearly, nothing important sits under text
or thumbnails, nothing gets cropped. Tell the user if something you'd agreed has to change.
