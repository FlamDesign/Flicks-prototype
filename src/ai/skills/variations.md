# Variations

## Choose
- 2 to 5. Default 3. Use 4 or 5 only when the product really has that many options worth seeing.
- Each one must be **visibly different at thumbnail size**: a different colour, product, person,
  scene or offer. Different text alone doesn't count.
- Prefer real options the user sells (from the website or the brief). Don't invent products.
- Spread them: light and dark, warm and cool, best-seller and statement piece.

## Order
- First: the best-seller or the most striking one (it's where the Flick starts).
- Alternate contrast so neighbouring thumbnails look different.

## Name
- Viewers see the name on the thumbnail's label: 1 or 2 words, max 14 characters
  ("Gold", "Sapphire", "Rust tiered"). Use the product's real name or colour.
- No numbering ("Variation 2"), no marketing filler ("Amazing gold").

## Per variation
- **label**: what viewers see above the headline, e.g. "Gold lenses" (optional).
- **price**: exact, with currency, e.g. "$189". Leave out if unknown; never guess prices.
- **link**: the exact product page for that option. Use the website's product URLs when read.
- headline, subheading, button text: only when they should differ (see the feeds skill).
