# Formats

| Size | Use | Notes |
|---|---|---|
| 1080×1920 (9:16) | Stories, Reels, TikTok, mobile web | Most room for text and strip |
| 1080×1080 (1:1) | Social feeds, website embeds | Balanced, safe default |
| 1920×1080 (16:9) | Website hero, CTV, YouTube | Text on one side, strip at the side or bottom |
| 300×600, 320×480 | Display ads (tall) | Short copy |
| 300×250, 336×280, 250×250, 480×320 | Display ads (small) | Headline ≤ 3 words, button, small strip |

- Where it runs: ads (served through placements), websites (embed code), or a shareable link.
  Same Flick everywhere; the size is chosen up front and can't change later.
- Length 6 to 15 seconds (default 8). Shorter loops better in ads.
- Each video costs credits by size and length; the plan card shows the total. Don't mention
  credits unless the user is short.
